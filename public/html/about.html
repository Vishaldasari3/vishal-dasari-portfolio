I’m a backend-focused engineer building cloud-native, event-driven systems in financial services and logistics.

Over 9+ years, I’ve worked across the full software lifecycle: designing services, shipping changes, and keeping production systems running reliably. Today I’m on the Revenue Reporting application team at JPMorgan Chase.

My core stack is Java, Spring Boot, and Kafka, alongside Python for data-heavy work. Recent projects include moving application servers to Amazon EKS, migrating SQL Server databases to Aurora PostgreSQL, and modernizing Hadoop pipelines with Databricks and Apache NiFi.
