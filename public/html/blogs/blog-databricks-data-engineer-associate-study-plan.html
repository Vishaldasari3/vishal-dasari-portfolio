🎯Certification Overview

  • Certification: Databricks Certified Data Engineer Associate

  • Number of Questions: 45 scored, with up to 10 additional unscored questions
  • Duration: 90 minutes
  • Passing Score: No numeric threshold published in the current official exam materials.
  • Cost: $200 USD + Applicable Taxes
  • Validity: 2 years

WEEK 1: Exam Orientation + Environment Setup

🎯 Goals:

  • Read the current seven-domain exam outline.
  • Explain how the workspace, compute, Delta Lake, and Unity Catalog fit together.
  • Select compute for development, scheduled data engineering, and SQL analytics.

📚 Resources:

Practice account setup

  1. Open the Free Edition signup link and select a signup method.
  2. Complete the signup prompts and open the workspace Databricks creates.
  3. Follow the notebook lab to run SQL and PySpark, then create a table.
  4. Use this workspace for the weekly exercises. Free Edition uses serverless compute with usage limits. For unavailable administrative features, record a configuration walkthrough.

  • 🎓 Get Started with Databricks for Data Engineering
  • 🎓 Databricks Fundamentals · official video training

Sign in to Academy and choose the self-paced course in the Self-Paced Training catalog. Course videos are available at no cost. Practise in Free Edition; Academy-hosted labs can require a separate subscription.

Weekly labs

  • 🧪 Lab · query data in your first notebook
  • 🧪 Lab · create a table and grant access

🔧 Tasks:

  • Set up a sandbox. Run a SQL query and a PySpark cell in a notebook.
  • Identify which component runs the query, stores data, and governs access.
  • Compare compute choices by capabilities, limitations, workload, and cost.
  • Complete one fresh compute-selection scenario and explain the workload, limitations, and cost tradeoff.

WEEK 2: Spark SQL Mastery & Query Optimization

🎯 Goals:

  • Transform bronze data into validated silver data in SQL and PySpark.
  • Choose suitable gold objects and explain basic Spark tuning.

📚 Resources:

  • 🎬 Tuning walkthrough · skew, task time, and shuffle partitions at 10:05
  • 🎬 PySpark transformations, joins, and aggregations · Ansh Lamba
  • 🎬 Gold views · start at 2:01:10
  • 🎬 Data quality checks · expectations demo at 30:59
  • 📘 Databricks SQL language reference
  • 📘 Apache Spark SQL and DataFrames

Databricks Academy

  • 🎓 Build Data Pipelines with Spark Declarative Pipelines

Weekly labs

  • 🧪 Gold objects and pipeline concepts

🔧 Tasks:

  • Handle nulls, casts, filters, column changes, and nested arrays. Practise inner, left, broadcast, multi-key, and cross joins.
  • Compare UNION and UNION ALL. Deduplicate and calculate counts, approximate distinct counts, and averages.
  • Compare tables, views, materialized views, and streaming tables for gold. Reconcile accepted and rejected records.
  • Explain shuffle partitions, default parallelism, broadcast threshold, and driver/executor memory. Measure before and after changing one applicable setting.
  • Explicitly practise adding, dropping, splitting, and renaming columns, plus DataFrame summary statistics. Identify spark.sql.shuffle.partitions, spark.default.parallelism, spark.sql.autoBroadcastJoinThreshold, spark.executor.memory, and spark.driver.memory in a tuning scenario.

📚 Resources:

  • 🎬 Managed table benefits and migration · Databricks

Weekly labs

  • 🧪 Table conversion procedure and requirements

🔧 Tasks:

  • Create a managed Delta table and compare its storage and deletion behavior with an external table.
  • Explain how and when to convert between managed and external tables. If external storage is unavailable, outline the configuration and expected outcome.
  • Use a governed Delta table as the destination for Week 4 ingestion.
  • Cover create, modify, delete, and managed/external conversion behavior. Record the expected storage and access outcome for each.
04

WEEK 4: Ingestion & Pipelines with Auto Loader + Workflows

🎯 Goals:

  • Select among batch, streaming, and incremental ingestion methods.
  • Configure Lakeflow Jobs and deploy its configuration through CI/CD.

📚 Resources:

  • 🎬 COPY INTO · incremental file loading
  • 🎬 Git folders · GitHub version control in Free Edition
  • 🎬 Auto Loader · start at 3:18:04
  • 🎬 Lakeflow Connect · getting started
  • 🎬 Lakeflow Jobs · orchestration, dependencies, and triggers
  • 🎬 CI/CD · bundles and deployment targets
  • 📘 COPY INTO reference

Databricks Academy

  • 🎓 Data Ingestion with Lakeflow Connect
  • 🎓 Deploy Workloads with Lakeflow Jobs · e-learning
  • 🎓 DevOps Essentials for Data Engineering · e-learning

Weekly labs

  • 🧪 Job tasks, dependencies, and triggers
  • 🧪 Bundle targets, variables, and CLI commands

🔧 Tasks:

  • Load files with COPY INTO and nested JSON with Auto Loader. Rerun and check counts. Compare schema enforcement, schema evolution, directory listing, and file notifications.
  • Choose among local upload, Auto Loader, Lakeflow Connect standard or managed connectors, partner connectors, JDBC/ODBC, and REST.
  • Build a job with dependencies, retries, conditions, and loops. Compare notebook, SQL query, pipeline, and dashboard tasks, plus scheduled, file-arrival, and table-update triggers.
  • Practise branch, commit, push, and pull request in Git folders. Set bundle variables and overrides for dev, test, and prod. Validate with the CLI and deploy to a sandbox if available.
  • Configure a connector’s source and governed target, and compare batch/incremental choices for nested or unstructured input. Sketch one JDBC/ODBC or REST ingestion. Promote both a job and a pipeline with bundle target overrides.
05

WEEK 5: Governance & Optimization

🎯 Goals:

  • Use job and Spark evidence to troubleshoot workloads.
  • Choose access controls and optimization techniques that fit the scenario.

📚 Resources:

  • 🎬 ABAC and masking · access-control demo at 06:57
  • 🎬 Troubleshooting · joins and spill at 04:27
  • 🎬 Managed tables and automatic optimization · start at 05:32
  • 🎬 Performance · liquid clustering
  • 🎬 Governance · Unity Catalog live demos
  • 🎬 Troubleshooting · query-history demo at 33:17
  • 📘 Databricks optimization documentation

Databricks Academy

  • 🎓 Databricks Performance Optimization
  • 🎓 Academy self-paced catalog · select Unity Catalog governance

Weekly labs

  • 🧪 Unity Catalog privileges reference
  • 🧪 ABAC policy behavior

🔧 Tasks:

  • Use job history and task status to find an upstream blocker. Read Spark UI metrics for skew, shuffle, and spill. Distinguish compute startup, dependency, and memory failures.
  • Compare liquid clustering with predictive optimization. Measure one change against a baseline.
  • Practise GRANT, REVOKE, and DENY at the appropriate scope. Compare access for users, groups, and service principals.
  • Predict what two groups can see under row filters, column masks, and centralized Unity Catalog ABAC.
  • Compare run duration and failure rate across job history. Use stage metrics to distinguish skew, shuffle, and disk spill. Test group-based filtering/masking and explain a centrally applied ABAC policy.

✅ Syllabus completion checks

Use the current official guide as the checklist. Record a lab result or a fresh scenario for every objective before the final mocks.

  • Week 1. Predict one SQL result and one PySpark result before executing. Explain a compute choice and its cost and limitations.
  • Week 2. Build a gold view and compare it with materialized views and streaming tables. Test duplicate keys, nulls, nested arrays, unmatched joins, and accepted/rejected counts.
  • Week 3. Practise creating, modifying, and deleting a disposable table. Use the current conversion procedure to check eligibility, permissions, storage changes, and supported reversal.
  • Week 4. Complete ingestion, orchestration, and deployment as separate study blocks. Choose a connector by volume, frequency, format, and governance. Inspect a deliberately failed DAG. Validate dev/test bundle targets and explain target overrides.
  • Week 5. Diagnose startup, library, and memory failures. Compare job duration and failure rate with a baseline. Predict effective access and group-specific row/mask results using the current privileges and ABAC references.
  • Week 6. Review every guessed answer, including correct guesses. Repair each untested objective and repeat with a fresh scenario before the last mock.
